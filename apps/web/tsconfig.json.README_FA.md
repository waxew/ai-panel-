# راهنمای فارسی `tsconfig.json`

فایل اصلی: `apps/web/tsconfig.json`

> JSON استاندارد کامنت را پشتیبانی نمی‌کند؛ بنابراین اگر داخل فایل اصلی `//` یا `#` بگذاریم ابزارهایی مثل npm یا TypeScript آن را نامعتبر می‌دانند. توضیح خط/کلیدها در این فایل کنار آن نگهداری می‌شود.

## `compilerOptions`
تنظیمات اصلی کامپایلر TypeScript را نگه می‌دارد.
- `target`: کلید «target» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `useDefineForClassFields`: کلید «useDefineForClassFields» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع boolean است.
- `lib`: کلید «lib» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع آرایه است.
- `allowJs`: کلید «allowJs» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع boolean است.
- `skipLibCheck`: کلید «skipLibCheck» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع boolean است.
- `esModuleInterop`: کلید «esModuleInterop» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع boolean است.
- `allowSyntheticDefaultImports`: کلید «allowSyntheticDefaultImports» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع boolean است.
- `strict`: کلید «strict» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع boolean است.
- `forceConsistentCasingInFileNames`: کلید «forceConsistentCasingInFileNames» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع boolean است.
- `module`: کلید «module» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `moduleResolution`: کلید «moduleResolution» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `resolveJsonModule`: کلید «resolveJsonModule» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع boolean است.
- `isolatedModules`: کلید «isolatedModules» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع boolean است.
- `noEmit`: کلید «noEmit» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع boolean است.
- `jsx`: کلید «jsx» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.

## `include`
کلید «include» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع آرایه است.
- `0`: کلید «0» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.

## `references`
کلید «references» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع آرایه است.
