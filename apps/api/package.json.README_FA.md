# راهنمای فارسی `package.json`

فایل اصلی: `apps/api/package.json`

> JSON استاندارد کامنت را پشتیبانی نمی‌کند؛ بنابراین اگر داخل فایل اصلی `//` یا `#` بگذاریم ابزارهایی مثل npm یا TypeScript آن را نامعتبر می‌دانند. توضیح خط/کلیدها در این فایل کنار آن نگهداری می‌شود.

## `name`
نام پکیج یا Workspace را مشخص می‌کند.
- مقدار فعلی: `@ai-panel/api`

## `private`
مشخص می‌کند پکیج نباید ناخواسته در Registry عمومی منتشر شود.
- مقدار فعلی: `true`

## `version`
نسخه پکیج را مشخص می‌کند.
- مقدار فعلی: `0.1.0`

## `type`
نوع سیستم ماژول Node، مانند ESM، را تعیین می‌کند.
- مقدار فعلی: `module`

## `scripts`
دستورهای قابل اجرای npm/pnpm را تعریف می‌کند.
- `dev`: کلید «dev» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `build`: کلید «build» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `start`: کلید «start» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `typecheck`: کلید «typecheck» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.

## `dependencies`
کتابخانه‌هایی را فهرست می‌کند که برنامه در Runtime به آن‌ها نیاز دارد.
- `@fastify/cors`: کلید «@fastify/cors» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `@fastify/static`: کلید «@fastify/static» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `@prisma/adapter-pg`: کلید «@prisma/adapter-pg» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `@prisma/client`: کلید «@prisma/client» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `dotenv`: کلید «dotenv» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `fastify`: کلید «fastify» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `pg`: کلید «pg» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `zod`: کلید «zod» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.

## `devDependencies`
ابزارهایی را فهرست می‌کند که بیشتر برای توسعه، Build، Typecheck یا تست استفاده می‌شوند.
- `@types/node`: کلید «@types/node» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `@types/pg`: کلید «@types/pg» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `tsx`: کلید «tsx» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
- `typescript`: کلید «typescript» بخشی از تنظیمات این فایل JSON است و مقدار آن از نوع string است.
